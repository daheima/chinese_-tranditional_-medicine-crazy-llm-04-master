## 项目经历

### 医疗知识图谱智能问答与临床辅助系统

**项目描述**

将中医知识图谱智能问答系统的完整技术架构迁移至现代医疗领域，基于 Neo4j 医学知识图谱与 LangGraph 多节点工作流，构建面向临床医生、护士及医学研究人员的智能辅助决策系统。系统能够检索疾病诊断依据、用药规范、药物相互作用、诊疗路径及最新临床指南，辅助临床决策。

**核心职责**

- 设计医疗领域知识图谱 Schema：节点类型包括疾病（Disease）、症状（Symptom）、药物（Drug）、检查项目（Examination）、手术操作（Operation）、临床指南（Guideline）、禁忌症（Contraindication）、不良反应（AdverseEffect）；关系类型包括表现为、治疗、禁用、相互作用、推荐等
- 从 UMLS、ICD-10、DRG 分组规则、临床指南数据库抽取医学实体与关系，通过 LLM 结构化处理导入 Neo4j，构建包含疾病-症状-药物-检查的完整医学图谱
- 使用 FAISS + 医学专用 Embedding 模型构建医学术语向量索引，将临床口语（如"患者发烧、咳嗽，白细胞高"）映射到标准医学实体
- 基于 LangGraph 设计临床意图识别节点：区分症状鉴别诊断、用药查询、药物相互作用核查、检查项目解读、手术禁忌查询等意图，分别路由至对应推理链路
- 实现药物相互作用核查节点：通过 Cypher 多跳查询识别患者用药组合中的潜在危险相互作用（如 A 药 + B 药 → 出血风险），生成用药警示
- 基于 `session_id` 实现医生与患者的会话绑定，历史对话记录患者主诉、检查结果等上下文，支持"这个患者的肾功能还正常吗"等跨轮次追问
- FastAPI 流式接口实时推送"正在检索诊疗指南"、"正在核查药物禁忌"等步骤，Streamlit 前端将推理过程折叠，展示最终临床建议并附参考指南出处
- 语义转写节点处理临床缩写与口语（"BP 高"→"高血压"，"转氨酶两位数"→"ALT/AST 轻度升高"）

**技术成果**

- 覆盖 ICD-10 全部疾病分类，支持 8000+ 种疾病的症状-诊断路径查询
- 药物相互作用核查覆盖 WHO 基本药物目录中的高风险组合，拦截率 > 95%
- 鉴别诊断建议与三甲医院标准诊疗路径吻合率 > 85%，辅助基层医生提升诊断质量
