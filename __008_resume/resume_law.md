## 项目经历

### 法律知识图谱智能问答系统

**项目描述**

将中医知识图谱智能问答系统的完整技术架构迁移至法律领域，基于 Neo4j 法律知识图谱与 LangGraph 多节点工作流，构建面向律师、法务人员及普通用户的智能法律咨询系统。系统能够理解法律语义，自动检索相关法条、判例、法律关系，支持多轮对话与实时流式输出。

**核心职责**

- 设计法律领域知识图谱 Schema：节点类型包括法律法规（Law）、法条（Article）、罪名（Crime）、刑罚（Penalty）、案由（Cause）、当事人类型（Party）、典型案例（Case）；关系类型包括规定、适用、引用、从属等
- 爬取裁判文书网、法律法规数据库，通过 LLM 批量抽取法律实体与关系，构建结构化法律知识图谱并导入 Neo4j
- 使用 FAISS + BGE-large-zh 构建法律术语向量索引，将用户口语化表述（如"打人坐什么牢"）映射到标准法律实体（故意伤害罪）
- 基于 LangGraph 实现法律意图识别节点：区分法条查询、案例检索、量刑参考、合同审查等不同意图，路由至对应处理节点
- 设计 Cypher 自动生成与校验机制，支持跨节点复杂查询（如"盗窃罪最高刑期对应的法条"），失败自动重试 3 次
- 基于 `InMemorySaver` + `session_id` 实现多用户会话隔离，支持律师与多个客户的并行咨询场景
- FastAPI 提供同步（`/process`）与流式（`/process_stream`）双接口，Streamlit 前端实时展示法条检索、推理路径和最终法律建议
- 实现语义转写节点：将"上次问的那个罪"等指代性表达结合历史对话还原为完整法律问题

**技术成果**

- 覆盖《刑法》《民法典》《劳动法》等核心法律，支持 10 万+ 法条的图谱查询
- 用户输入法律问题到返回法条依据，端到端响应时间 < 8 秒
- 流式输出实时显示"正在检索法条"、"正在生成法律建议"等推理步骤，提升用户信任度
