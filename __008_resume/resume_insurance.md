## 项目经历

### 保险知识图谱智能问答系统

**项目描述**

将中医知识图谱智能问答系统的技术架构迁移至保险行业，基于 Neo4j 保险产品知识图谱与 LangGraph 工作流，构建面向保险代理人与投保用户的智能问答系统。系统支持产品条款查询、责任范围判断、理赔路径引导、核保规则检索等场景，并通过多轮对话帮助用户理解复杂保险条款。

**核心职责**

- 设计保险领域知识图谱 Schema：节点类型包括保险产品（Product）、保险责任（Coverage）、免责条款（Exclusion）、理赔条件（ClaimCondition）、疾病（Disease）、职业类别（Occupation）、费率表（RateTable）；关系类型包括承保、免责、关联疾病、适用职业等
- 爬取各保险公司官网条款文本及银保监会公示数据，通过 LLM 结构化抽取保险产品实体与责任关系，导入 Neo4j 构建统一产品知识图谱
- 使用 FAISS + BGE-large-zh 构建保险术语向量索引，将用户口语化表述（如"住院能报销吗"）映射到标准保险概念（住院医疗险 / 住院津贴险）
- 基于 LangGraph 设计多意图路由节点：区分产品查询、条款解释、理赔指引、保费估算等意图，路由至对应处理链路
- 实现核保规则推理节点：根据用户健康告知信息（既往病史、职业、年龄），结合图谱中的核保规则节点，判断是否可承保及附加条件
- 基于 `session_id` 实现用户会话隔离，支持保险代理人同时服务多个客户的并发场景，历史对话用于跟踪用户的投保意向和已确认信息
- FastAPI 流式接口实时推送"正在匹配产品条款"、"正在检索免责条款"等进度信息，Streamlit 前端将推理过程折叠展示，最终输出清晰的条款解释和建议
- 实现语义转写节点：将多轮对话中的指代（"这个产品"、"刚才说的那个疾病"）结合历史记录还原为完整查询意图

**技术成果**

- 覆盖重疾险、医疗险、寿险、意外险等主流险种，支持 500+ 款在售产品的条款查询
- 理赔路径引导准确率相比纯 LLM 方式提升 40%，减少因条款理解偏差导致的理赔纠纷
- 核保规则推理支持复杂条件组合判断（如"糖尿病 + 高危职业 + 年龄 55 岁"的可保性判断）
