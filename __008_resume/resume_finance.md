## 项目经历

### 金融知识图谱智能问答系统

**项目描述**

将中医知识图谱智能问答系统的技术架构迁移至金融领域，基于 Neo4j 金融知识图谱与 LangGraph 多节点工作流，构建面向投研分析师、风控人员及理财顾问的智能辅助系统。系统能够解析金融产品信息、企业关联关系、监管规则及市场数据，支持复杂金融问题的结构化检索与推理。

**核心职责**

- 设计金融领域知识图谱 Schema：节点类型包括企业（Company）、产品（Product）、基金（Fund）、股东（Shareholder）、监管规则（Regulation）、财务指标（FinancialMetric）、风险事件（RiskEvent）；关系类型包括持股、担保、关联交易、监管适用等
- 通过 LLM 批量抽取上市公司公告、基金招募说明书、监管文件中的实体与关系，构建企业关联图谱与金融产品图谱并导入 Neo4j
- 使用 FAISS + BGE-large-zh 构建金融术语向量索引，将用户输入（如"这只基金的风险"）映射到标准金融实体（基金名称、风险等级节点）
- 基于 LangGraph 设计多意图路由节点：区分企业背调、产品查询、风险预警、监管合规查询、投资组合分析等意图，分别路由至对应 Cypher 生成链路
- 实现穿透持股推理节点：通过多跳 Cypher 查询（`MATCH path = (a)-[:HOLDS*1..5]->(b)`）识别企业实际控制人与关联方，支持反洗钱、关联交易识别场景
- 基于 `session_id` 实现多分析师会话隔离，历史对话追踪分析师当前关注的企业或产品，上下文理解"它上季度的净利润"等指代表达
- FastAPI 流式接口实时推送图谱查询进度，Streamlit 前端展示推理路径与最终分析结论，推理过程可折叠审查
- 实现 Cypher 生成的金融规则约束：LLM 生成查询时注入金融图谱 Schema 提示，防止生成无效路径；校验失败自动重试 3 次

**技术成果**

- 支持企业 5 层穿透持股查询，识别隐性关联方，辅助风控人员快速完成企业背调
- 基金产品查询响应时间 < 5 秒，支持自然语言提问"沪深 300 指数基金中费率最低的 5 只"
- 多轮对话支持投研分析师连续追问，上下文保留当前分析标的，减少重复输入
